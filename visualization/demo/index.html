A shared scale, with visible assumptions.

Strength comes from the two costs

Both cost axes use u(T) = log₂ log₂ T. Strength is their difference: u(TC) − u(TQ). A square-root improvement has strength 1; an exponential-to-polynomial comparison moves as N grows. The background and every point use this same value.

The plotted costs are leading-order asymptotic models evaluated at N, with constants and the stated lower-order factors suppressed. Each detail panel gives the input parameter and resource being counted.

Evidence uses explicit anchors

0: no established speedup; 0.5: best-known classical comparison; 0.75: conditional hardness; 1: rigorous oracle separation. These are evidence categories placed on a continuous axis. Proven oracle comparisons share the same height.

Hardware uses a resource model

The coordinate is log₁₀(Q × G), where Q is modeled logical storage and G is modeled coherent work. Query algorithms use the chosen gate cost per query. Each panel exposes Q and G. This is an editable resource estimate; physical error correction and oracle construction are additional implementation inputs.
