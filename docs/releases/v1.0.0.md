Quantum Speedup Map v1.0.0 is the first stable release of **Quantum Speedups for Discrete Computational Problems**.

The release contains 211 problem entries, 165 shared algorithm records and 296 literature records. The interactive map shows 210 algorithm-bearing entries, with 197 principal complexity comparisons in the two-dimensional plot and 13 entries without a matched complexity bound below it.

The website includes linked problem and algorithm pages, literature locations, search, Oracle/Gate resource filters, fullscreen views and an offline edition. Each plotted comparison uses its principal regime or a documented regime with the strongest quantum advantage.

## Downloads

- `quantum-speedup-map-v1.0.0.html`: the complete offline website; open it directly in a browser.
- `quantum-speedup-map-data-v1.0.0.zip`: the JSON catalogue, references, relationships and plotting comparisons, with version and citation information.
- `quantum-speedups-v1.0.0.sqlite`: the searchable SQLite database.
